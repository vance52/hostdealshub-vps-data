# HostDealsHub VPS pricing data

This repository publishes a small, auditable snapshot of VPS prices exposed on official provider pages. It is intended for comparison, research, and reproducible filtering—not as a guarantee that a plan is still available at checkout.

The maintained website and human-readable comparisons are at [HostDealsHub](https://hostdealshub.com/).

## What is included

- `data/offers.json` — the provenance-rich source snapshot generated by the HostDealsHub pipeline.
- `data/vps_offers.csv` — the same verified offers in a flat table.
- `data/providers.md` — every configured provider, official source, last check time, result status, and verified-offer count.
- `tools/filter_offers.py` — a standard-library command-line filter for provider, currency, and maximum price.
- `scripts/export_snapshot.py` — the deterministic JSON-to-CSV/Markdown exporter.
- `.github/workflows/refresh.yml` — validates the public snapshot, regenerates derived files, runs tests, and commits real changes every six hours.

Every priced row keeps its official `source_url` and `fetched_at` timestamp. A provider may have zero rows when its official page is unavailable, blocked to automation, or does not expose an unambiguous price. Missing data is not estimated.

## Quick use

```bash
python tools/filter_offers.py --provider DigitalOcean --max-price 12
python tools/filter_offers.py --currency USD --format json
```

Rebuild the derived files after replacing `data/offers.json` with a newer snapshot:

```bash
python scripts/export_snapshot.py
python -m unittest discover -s tests
```

The scheduled workflow refuses to replace the dataset if the download is not a HostDealsHub payload, has no offers or providers, reports an inconsistent offer count, or contains a priced row without provenance.

## Fields

The CSV contains:

`provider`, `title`, `price`, `currency`, `billing_period`, `offer_url`, `source_url`, `fetched_at`, `extraction`, `valid_until`, `id`

The official provider page remains the source of truth. Prices can change after the recorded fetch time, and taxes, regions, introductory terms, or checkout conditions may differ.

## Data policy

- Official public pages only.
- No login-only sources or anti-bot bypass.
- No guessed prices, dates, discounts, reviews, or commissions.
- Source URL and fetch time remain attached to every published price.
